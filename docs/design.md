# Hearthvale 游戏设计

## 游戏定位

Hearthvale 是一款中世纪西幻 RPG / Living World 游戏。

玩家是这个世界中的人物，而不是脱离世界存在的经营管理者。玩家的经营、交往、探索和战斗都发生在同一个持续运转的世界中，并与其中的地点、角色和事件产生联系。

## 当前内容范围

游戏内容目前主要聚焦于：

- 一个小镇
- 小镇周围的野外
- 玩家经营的一间酒馆

酒馆经营是当前主要游戏内容，也是玩家接触小镇居民、旅人、商品和情报的重要场所，但不是整个游戏设计或底层系统的唯一目标。

## 空间表现

Hearthvale 采用 2D 俯视角。建筑内部、小镇街道、后院、森林、道路以及其他室内外地点，都通过俯视场景表现。

游戏使用两级空间结构：

- 世界层由可以进入、活动和离开的世界节点（Location）组成。酒馆、酒馆后院、小镇街道、商铺和野外地点在这一层级中地位相同，不因室内或室外而采用不同体系。
- 场景层把每个世界节点表现为可游玩的 2D 格子场景。格子组织地面、墙壁、障碍、道路、门、出口、建筑结构以及家具等空间内容。

格子负责组织场景，玩家并不逐格移动。玩家采用上下左右四方向连续移动，并具有对应朝向、碰撞和镜头跟随。

世界节点通过场景出口直接连接。每个出口既指向目标节点，也对应目标场景中的具体进入位置，使玩家可以从一个地点离开并从另一个地点的对应入口出现。

当前不引入 Region、国家或大陆等更高空间层级。

## 总体内容方向

### 酒馆经营与发展

玩家可以围绕酒馆开展经营活动，包括：

- 酒品和食物交易
- 情报交流
- 家具购买与酒馆改造
- 酒馆扩张
- 后院种植
- 烹饪与生产
- 雇佣店员

酒馆不仅是经营界面，也处在游戏世界之中。酒馆里的角色、工作、交易和事件应当与小镇及周边世界发生联系。

### 居民、旅人与日常生活

小镇中存在居民和往来的旅人。NPC 有自己的工作与生活，会进入酒馆、交换情报、参与交易，并与玩家及其他角色产生互动。

这些角色共同构成游戏的 Living World。玩家是其中的一员，与 NPC 生活在同一个世界背景和游戏规则下。

### 野外、冲突与动态事件

小镇周围的野外为玩家提供酒馆之外的活动空间。已经明确的内容包括：

- 野外探索与狩猎
- 战斗
- 魔兽袭击
- 闹事客人等动态事件

这些内容让酒馆经营、小镇生活和外部世界之间能够相互影响，而不是成为彼此隔离的玩法集合。

## 当前设计边界

本文只记录游戏的总体方向和已经明确的内容范围。具体数值、配方、物品表、职业表、NPC 属性字段以及各玩法的详细规则，均在出现真实设计需求时另行确定。
